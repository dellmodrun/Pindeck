# Pindeck

Pindeck 的静态前端与 GitHub Pages 发布仓库。

## 本地预览

```powershell
npm start
```

默认地址为 `http://127.0.0.1:4173`，可通过 `PORT` 环境变量更改端口。

## GitHub Pages

```powershell
npm run build:pages
```

构建结果会写入 `_site/`，仓库工作流会自动发布到 GitHub Pages。
